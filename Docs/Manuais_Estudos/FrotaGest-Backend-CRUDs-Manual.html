Perguntas para o estudo


O que é um CRUD?
O conjunto de ecrãs para Criar, Ler, Atualizar e Apagar registos de uma tabela. O Gii gera-o a partir de um modelo.


Que ficheiros gera o Gii por cada CRUD?
Um controlador (ViaturaController), um modelo de pesquisa (ViaturaSearch) e as vistas index, view, create, update, _form e _search.


Porque é que "Viaturas disponíveis" e "Requisições pendentes" não têm CRUD próprio?
Porque não são tabelas, são filtros. Usam o CRUD de viaturas e o de requisições, com o parâmetro ViaturaSearch[estado]=disponivel ou RequisicaoSearch[estado]=pendente no endereço.


Porque é que o delete só aceita POST?
Para um link ou um robô que abra a página não apagar registos. O VerbFilter do behaviors() trata disso, e o botão da listagem envia um formulário POST.


Para que serve o modelo de pesquisa (...Search)?
Alimenta os filtros por coluna da GridView da listagem. Tem rules() só de leitura e o método search(), que devolve um ActiveDataProvider.


O que quer dizer roles => ['@'] no AccessControl?
Utilizador autenticado. ? quer dizer visitante (sem login).


De onde vem o texto "Não foram encontrados resultados."?
Do Yii, não do projeto. É a tradução de "No results found." em vendor/yiisoft/yii2/messages/pt/yii.php, usada pela GridView quando não há linhas. Para o mudar usa emptyText na GridView.


Onde se muda o menu da esquerda?
Em backend/views/layouts/sidebar.php, no array items do Menu::widget.



Erros que podem aparecer


Only word characters and backslashes are allowed ao correr o Gii
Usaste aspas duplas e o Git Bash apagou as barras. Põe as classes entre aspas simples (passo 4).


The view file does not exist: .../backend/views/viatura/index.php
As vistas foram geradas em console/views. Move-as para backend/views (passo 5).


Erro 500 com Class "backend\controllers\AccessControl" not found
Falta o use yii\filters\AccessControl; no topo do controlador (passo 6).


O link do menu abre "Not Found (#404)"
Escreveste mal a rota. Tem de ser o nome do controlador em minúsculas: ['/viatura/index'].


"Integrity constraint violation" ao gravar ou apagar
A tabela tem chaves estrangeiras. Para criar, o registo ligado (ex. a categoria) tem de existir; para apagar, não pode ter registos que dependam dele.


Qualquer pessoa abre o CRUD sem login
O controlador não tem o bloco 'access' no behaviors() (passo 6).


Texto ainda em inglês numa página
Ou é texto fixo da vista/etiqueta do modelo (passo 8), ou falta o 'language' => 'pt' no main.php do backend.
