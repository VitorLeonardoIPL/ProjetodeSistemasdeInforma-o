Como trocar o aspeto do frontend do Yii pelo template Cental (HTML Codex): copiar os ficheiros do template, carregá-los com o AppAsset, usar o Bootstrap do template, refazer o layout (menu, rodapé, banner) e começar a página inicial com os textos da especificação. Marca cada passo quando o tiveres feito e abre o código para veres o que escrever.

O que se pede

O frontend é o front-office: o site que o Colaborador usa para iniciar sessão, consultar viaturas e fazer requisições. Ainda tinha o aspeto e os textos de exemplo do Yii ("My Application", "Build with Yii Framework"). O enunciado pede que o front-office use um template do HTML Codex. Escolhemos o Cental.

Os passos

Abre cada passo, faz o que diz e marca a caixa. O progresso fica guardado no browser. Depois de cada passo testa com Ctrl + F5 (recarrega sem usar a cache).

1Escolher o template e perceber a licençahtmlcodex.com
O que fazer
  1. Descarrega o Cental – Car Rent Website Template em https://htmlcodex.com/car-rent-website-template/ (botão DOWNLOAD NOW).
  2. Extrai o Cental.zip (botão direito → Extrair tudo). Lá dentro, a pasta Cental tem os .html e as pastas css, js, img e lib.
Porquê
  • O Cental usa Bootstrap 5, tal como o Yii (yii\bootstrap5). Assim os formulários e widgets do Yii ficam com bom aspeto sem conflitos.
  • Tem páginas de viaturas e um carrossel, que encaixam no catálogo do FrotaGest.
  • É gratuito com licença CC BY 4.0: o crédito "Designed By HTML Codex" no rodapé não se pode remover.
  • Os .html do template nunca se alteram. Servem só de modelo para copiar pedaços de HTML.
Verifica: tens a pasta Cental extraída (por exemplo, nas Transferências).
2Copiar os ficheiros do template para o projetofrontend/web
O que fazer
  1. Copia as 4 pastas css, js, img e lib do Cental para FrotaGest\frontend\web\. Já existe uma pasta css (com o site.css): aceita juntar as pastas.
  2. Apaga lib\waypoints\links.php.
  3. Não copies os .html.
Porquê
  • No Yii, a única pasta que o browser vê é a frontend/web (a pasta pública). CSS, JS e imagens têm de estar lá.
  • O links.php não é usado e é PHP dentro da pasta pública: mais vale não o deixar lá.
  • O img\Thumbs.db (cache do Windows) é um ficheiro oculto e o FrotaGest/.gitignore já o ignora. Não é preciso apagá-lo.
Verifica: o GitHub Desktop mostra 46 ficheiros novos, todos dentro de FrotaGest/frontend/web/.
3Carregar o CSS e o JS do template (AppAsset)frontend/assets/AppAsset.php
O que é

Num site HTML escreves os <link> e <script> à mão. No Yii há uma classe, o Asset Bundle, com a lista dos CSS e JS. O layout regista-a e o Yii escreve as tags sozinho: os CSS em $this->head() e os JS em $this->endBody().

O que fazer

No AppAsset.php, troca o $css e acrescenta o $js. Os itens vêm do <head> e do fim do index.html do Cental:

frontend/assets/AppAsset.php


Porquê


    

  • Os caminhos sem https:// são relativos a frontend/web, porque a classe tem $basePath = '@webroot' e $baseUrl = '@web'.
    • 

  • A ordem conta: quando dois CSS mudam a mesma coisa, ganha o último. O site.css fica no fim para poder alterar o template.
    • 

  • O jQuery e o bootstrap.bundle do index.html não se põem: o Yii já os carrega pelo $depends (YiiAsset e Bootstrap). Ficariam duplicados.
    • 

  • O $depends diz que bundles têm de ser carregados antes deste.
    •

Perguntas para o estudo


Porque é que os ficheiros do template vão para frontend/web?
É a única pasta pública do frontend: o browser só consegue carregar CSS, JS e imagens que estejam lá.


O que é um Asset Bundle?
Uma classe com a lista dos CSS e JS (e das dependências). O layout regista-a e o Yii escreve as tags <link> no head() e os <script> no endBody(), pela ordem certa e sem repetir.


Para que serve o $depends?
Diz que bundles têm de ser carregados antes deste. O YiiAsset traz o jQuery, de que o main.js do template precisa.


Porque é que o Bootstrap do template se troca no config/main.php e não no AppAsset?
Porque os widgets do Yii também pedem o BootstrapAsset. Configurado no assetManager, todos passam a receber o ficheiro do template, e não há dois Bootstraps na página.


Qual a diferença entre a view e o layout?
A view é o conteúdo de uma página; o layout é a moldura comum. A view entra no layout pela variável $content.


Como é que o layout sabe o título e os breadcrumbs de cada página?
A view define $this->title e $this->params['breadcrumbs']. Como a view corre antes do layout, quando o main.php corre os valores já estão preenchidos.


Para que serve o semBanner?
É um parâmetro nosso: a página inicial põe-no a true e o main.php não mostra o banner e deixa o conteúdo a toda a largura (sem o container).


Porque é que não há botão "Registar"?
Pela especificação, só o Administrador cria contas, no back-office, e atribui o role. O Colaborador só inicia sessão.


Porque Html::img('@web/img/x.jpg') e não <img src="img/x.jpg">?
O caminho relativo depende do URL da página. O @web é substituído pelo URL da pasta frontend/web, e fica sempre certo.


Para que serve o Html::encode()?
Transforma < e > em texto, para que dados vindos da BD (ex.: um username) não sejam interpretados como HTML.



Erros que podem aparecer


Mudei um ficheiro e no browser nada muda
Ou o ficheiro não foi gravado (Ctrl + S), ou foi alterado no clone de Documents\GitHub em vez do clone do WAMP, ou o browser usou a cache (faz Ctrl + F5).


As pastas não aparecem / o GitHub Desktop mostra um número diferente
Foram copiadas para o clone errado. Confirma em Repository → Show in Explorer que o GitHub Desktop abre a pasta do WAMP.


Não encontro o Thumbs.db
É um ficheiro oculto do Windows e o .gitignore já o ignora. Não é preciso apagá-lo.


404 na consola (F12) com bootstrap.min.css.map
O CSS do template aponta para um ficheiro .map que não vem no ZIP. Só serve para depurar CSS; não afeta nada.


Cores e fontes misturadas depois do passo 3
É normal até ao passo 4: o Yii ainda carrega o Bootstrap dele, e o HTML ainda é o do Yii.


Espaço vazio grande por baixo do menu
É o padding de 70px do site.css, feito para o menu antigo. Passa a 0 (passo 9).


Buraco à direita no rodapé
As colunas não somam 12. Com 2 colunas, as duas levam col-lg-6.


O carrossel tem margens dos lados
O conteúdo está dentro do container. A página inicial precisa do $this->params['semBanner'] = true; e do if do main.php (passo 9).


O título aparece repetido (no banner e na página)
O do banner vem do layout; o outro é da própria view, que ainda é a do Yii. Sai quando se adaptar cada página.
